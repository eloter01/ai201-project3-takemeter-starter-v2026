# Working notes

## Community

**4forums.com**, a public debate forum where people argued about politics and
social issues like gun control, abortion, and gay rights.

The forum no longer exists, so I read and collected the posts from the
Internet Argument Corpus, a research dataset of 4forums.com threads.

## Candidate distinctions

Things I noticed while reading 30–40 posts. Each one is something I can point
at in the text, not "good vs. bad".

1. **Numerical references:** Some comments include specific numbers or
   statistics; most do not.
2. **External sources:** Some comments cite or link to an external source;
   most do not.
3. **Questions:** Some comments explicitly ask a question; others make
   statements without asking one.
4. **Personal experience:** Some comments refer to the author's own
   experiences or life; others discuss the issue without personal anecdotes.
